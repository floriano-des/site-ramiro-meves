# Materiais locais da campanha

Os materiais originais estão em `materiais/originais/` e somam aproximadamente 2,5 GB. Essa pasta é ignorada pelo Git para evitar arquivos grandes, fontes brutas e documentos internos no repositório público.

Conteúdo principal recebido:

- briefing do site;
- plataforma política;
- manifesto;
- banco de frases P, M e G;
- manual e arquivos de identidade visual;
- logos, número, fundos, molduras e fontes;
- fotos de campanha, PSDs e materiais históricos;
- peças de motion e vídeos.

Não editar os originais. Quando um arquivo for escolhido para o site, criar uma cópia otimizada em `assets/`.
