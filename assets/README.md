# Assets de produção

Esta pasta recebe somente arquivos usados pelo site e preparados para a web.

- `images/`: fotos e imagens otimizadas, preferencialmente WebP ou AVIF.
- `fonts/`: fontes finais em WOFF2, com licenças verificadas.
- `icons/`: ícones e arquivos SVG sanitizados.
- `media/`: vídeos e animações realmente publicados.

Os arquivos brutos e editáveis permanecem em `materiais/originais/` e não entram no GitHub.
